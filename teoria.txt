ORDEN DE LOS ARCHIVOS DEL BOT SEGÚN LÓGICA:

1. intents.json --> la "materia prima" que la IA va a aprender
Archivo de datos puro (no hay código). Todas las posibles respuestas del bot vienen de acá. Si algo falta, la red no lo va a aprender nunca. Su estructura es simpre la misma por c/tema:
{
  "tag": "documentacion",    
  "patterns": ["constancia de alumno", "certificado regular"],  
  "responses": ["La constancia de alumno regular se piden en Secretaría"]
}

*tag: nombre de la categoría (etiqueta interna) que la red va a intentar predecir
*patterns:  ejemplos de cómo se podría preguntar una misma cosa. Cuántas más formas de preguntar tenga, mejot generaliza la red ("Destacado" --> 8-10)
*responses: respuesta del bot. Es una lista para que haya más de una opción y se elija al azar

2. train.py --> entrenamiento de la red neuronal




3. app.py --> levanta el modelo entrenado como API
4. index.html --> pantalla web que comunica con API
